# Smallframe architecture evidence

Status: Candidate U local Phase 0 evidence is green; the normative architecture amendment in ADR-0005 still requires founder acceptance.

Smallframe has three browser realms. The trusted controller currently owns local state, renderer verification, and DOM chrome; the target trust boundary also assigns it room capabilities, persistence, and package verification once those phases are implemented. A build-pinned renderer response is synthesized and cached by the controller Service Worker, then navigated only after the controller independently hashes and checks its exact response policy. Publisher code runs only in a classic Blob Worker created by that renderer and can emit only the declarative SDK protocol.

Candidate U uses the browser shape that actually passed in Chromium, Firefox, and WebKit: the renderer response CSP contains `sandbox allow-scripts`, while the iframe omits the HTML `sandbox` attribute because opaque sandbox navigation with that attribute bypassed Service Worker control in the tested engines. The renderer's effective opaque-origin evidence is `self.origin === "null"`, parent-observed message origin `null`, denied parent DOM/storage/network authority, and a `blob:null/` Worker. `location.origin` is URL diagnostics, not the security oracle.

The renderer creates one classic Blob Worker. A trusted lexical sibling installs first, captures intrinsics, runs the build-pinned 135-byte Wasm startup probe, and owns the only trusted MessagePort. All controller/renderer and renderer/Worker traffic uses exact schemas, protocol/session identifiers, monotonic sequences, 256 KiB limits, one-use port transfers, explicit lifecycle states, and fail-closed `messageerror`/timeout handling. The controller removes a fatal renderer iframe. A one-second external watchdog permits one restart from the last accepted state, then fail-stops.

The local API spike is a separate Cloudflare Worker with strict startup configuration, D1/R2/DO binding validation, centralized security headers, exact CORS, and a SQLite Durable Object. It proves opaque-byte CAS intended to carry caller-produced ciphertext, capability-hash checks, 30-second one-use WebSocket tickets, held-fetch behavior, conditional state GET, bounded 512 KiB streaming PUT, and room-expiry alarm behavior in Miniflare. It does not perform encryption or envelope validation and is not the Phase 3 production relay: signatures, encrypted envelope validation, recovery epochs, rotation/revocation, checkpoints, and full abuse quotas remain design decisions only.

The authoritative rationale and deviations are in ADR-0005. Package identity, encryption, CRDT genesis, recovery lineage, and Cloudflare persistence decisions are in ADR-0006 through ADR-0010. Local tests are not an independent security audit, deployed Cloudflare proof, or market validation.
